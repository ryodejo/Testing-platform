## Запланировано для ручной проверки человеком

Эти пункты не выдаются за выполненные:

- [ ] Пройти полный тест с отключённым JavaScript; подтвердить пропуски после серверного предупреждения.
- [ ] Пройти страницы только с клавиатуры (Tab/Shift+Tab/стрелки/Space); проверить порядок фокуса.
- [ ] Проверить озвучивание подписей, ошибок и групп вопросов NVDA/другим screen reader.
