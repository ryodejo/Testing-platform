- Миграция 0007 уже применена, но в `Test` отсутствовали её поля `difficulty`, `is_active`, `time_limit`, `topic`, `updated_at` и часть Meta-опций.

## Реализовано

Стандартная авторизация Django, обязательный email и подтверждение пароля, нормализация/проверка адреса и защита от новых конфликтов на уровне SQLite. Унаследованные повторяющиеся адреса не изменяются автоматически. Использованы стандартные LoginView/LogoutView/PasswordReset*View, console backend и настройки SMTP через окружение. Обработчик ошибки CSRF выводит согласованную страницу 403 без внутренних причин.

Каталог опубликованных непустых тестов, поиск, темы, карточки и описание перед началом. Сохранены исходные категории и иерархия разделов. `Test.is_active` для новых тестов по умолчанию False; проверяются вопросы, минимум два варианта и ровно один правильный ответ.

Новые черновики создаются только через POST; завершение сохраняет результат и снимки ответов одной транзакцией. Клиентские баллы, чужие вопросы/варианты, повторяющиеся значения и чужие черновики отклоняются. UUID результата уникален. SQLite IMMEDIATE сериализует конкурентную запись. GET-обновление, повтор POST и одновременные повторы не создают второй результат.

После отправки доступны баллы, процент, выбранные/правильные ответы и объяснения; история содержит только свои попытки. Завершённые снимки не зависят от изменений/удаления исходных материалов. В старых результатах не выдумывается неизвестный total/процент.

Django Admin получил inline-формы, поиск и фильтры. Результаты доступны только для чтения. Для изменения структуры опубликованный тест нужно сначала снять с публикации. Опубликованные варианты проверяются inline; переносы между вопросами/разделами через одиночные формы запрещены.

Добавлены команды `backup_db` и `seed_demo`: четыре учебных теста по пять вопросов с объяснениями. Повтор команды не меняет старые материалы и не создаёт копии. Создание администратора оставлено стандартному createsuperuser.

Полностью обновлены общие шаблоны и локальные CSS/JS: русский язык, светлый фон, индиго, системные шрифты, responsive-сетка, видимые подписи/ошибки, состояния фокуса и недоступности, страницы 403/404/500. Нет внешних шрифтов, CDN, фиктивных отзывов или статистики.

Настройки и секреты читаются из окружения. `scripts/dev.ps1` создаёт случайный постоянный локальный ключ в игнорируемом `.local`; DEBUG=0 требует HTTPS для secure cookies. Старый секрет из исходного файла больше не используется. Виртуальное окружение и зависимости локальные.

## Исправления, найденные при проверках

- Первичная запись новых файлов через PowerShell stdin повредила кириллицу; файлы переписаны в UTF-8, повреждённые строки не остались в активных шаблонах/исходниках.
- Тест повторяющегося HTTP-поля первоначально кодировал лишь последнее значение QueryDict; теперь отправляет настоящий список значений и подтверждает серверный отказ.
- Стандартная страница CSRF отличалась от общего дизайна; подключён собственный CSRF_FAILURE_VIEW при сохранённом middleware и реальном отказе 403.
- После визуального просмотра уточнён стиль длинного ника и повторена браузерная проверка с отключённым кешем.
- Пустые старые опубликованные тесты не удалены, но больше не предлагаются в каталоге; прямая страница показывает недоступность, сервер также отклоняет начало.

## Ограничения и непроверенные области

SMTP-доставка не выполнялась, сброс проверен locmem backend и стандартным Django-токеном. Реальные устройства, Firefox/Safari, полный ручной клавиатурный проход, screen reader и production HTTPS — **не проверены**, отмечены планом в manual-testing.md. Это не результаты выполненных проверок.

Старые ответы и общее число вопросов отсутствовали в базе — их восстановление невозможно без выдумывания. В исходных аккаунтах остаются прежние повторяющиеся email. Для публичного сервиса потребуется согласовать адреса, ограничение частоты запросов/почты, HTTPS, production-статику, очистку черновиков и отдельную оценку нагрузки. SQLite и встроенный runserver предназначены для учебного локального запуска.

Все временные серверы и браузер проверки закрыты после завершения. Git push, коммит, публикация и развёртывание не выполнялись.
